# Nota Themes 0.8.0-beta

This release adds native interface icon packages and aligns Yaru more closely
with Ubuntu's GTK 4 design.

## Interface themes

- Adwaita, Yaru, Breeze/Plasma, GitHub, Windows 11, Windows 10 and macOS now
  include package-local icons from their corresponding upstream design systems.
- Each icon package retains its upstream license and checksum manifest.
- Yaru light and dark palettes now follow GTK 4 window, header and view colors.
- Theme packages remain self-contained; dropping a theme folder into Nota does
  not require the build system.

## Packages

- `nota-ui-themes-0.8.0.zip`
- `nota-document-themes-0.8.0.zip`

The document theme package remains available for users who want the complete
official document theme collection alongside the updated interface assets.
